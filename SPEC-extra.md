# Ak spec: extras (read only when needed)
Native target only.
## Details
Native only (sockets, IPv4 TCP, blocking): `(tcpl port host="0.0.0.0")` listen → fd (port 0 = pick one) · `(tcpp fd)` local port · `(tcpa fd)` accept → fd · `(tcpc host port)` connect → fd (host: dotted IPv4, `localhost`, or a name in /etc/hosts; no DNS/TLS) · `(fdr fd n=65536)` read ≤n bytes (`""` = end of stream) · `(fdw fd s)` write all (string, byte list or `u8`) · `(fdc fd)` close · `(fdwait [fd ..] ms)` → the readable fds (ms<0: forever) — see `examples/httpd.ak`. `pow`/`**` with fractional exponents may differ from V8 in the last digit; all other math functions are bit-identical to V8. Uncaught errors print `error: msg (file:line:col)` and exit 1. Memory is garbage-collected (copying GC); for stress testing set `AK_GCMIN=<bytes>` (collect after every that many bytes allocated), `AK_GCVERIFY=1` (heap verifier) and `AK_GCSTATS=1` (print the collection count at exit).
## Windows and graphics (native only, Linux X11 / XWayland)
No libraries: `lib/x11.ak` speaks the X11 protocol itself over the display's socket (`$DISPLAY`, cookie from `$XAUTHORITY` / `~/.Xauthority`), `lib/canvas.ak` draws in software. `(use "../lib/x11.ak")` includes both. Needs a depth-24 display; the window has a fixed size.
`cv=(canvas w h)` (BGRA pixels in `cv.px`) · `(fill cv c)` `(rect cv x y w h c a=255)` `(rrect cv x y w h r c)` `(circle cv cx cy r c a=255)` `(ring cv cx cy r thick c)` `(vgrad cv x y w h c1 c2)` anti-aliased; colours are `(rgb r g b)` numbers, `a` is opacity 0..255 · `(text cv x y "str" size c a=255)` → width (sizes 15 22 regular, 34 bold; ASCII; DejaVu, see `lib/FONT-LICENSE.txt`) `(text_w "str" size)` · `(blit dst dx dy src sx sy w h mask)` copy a region (mask: a canvas whose blue channel is the opacity, or nil) · `(copy_canvas dst src)` `(px cv x y)` `(save_ppm cv "f.ppm")`.
`w=(gui_open "title" width height)` · `(gui_present w cv)` shows a canvas (it is repainted by itself when uncovered) · `(gui_event w ms)` → the next event or nil after `ms` ms (no `ms`: sleep until one arrives, 0 CPU): `{:type "key" :key :down :shift :ctrl}` (keys are `"left" "enter" "esc" "tab" "backspace" "delete" "home" "end" "shift" "ctrl" "alt"` or the typed character) · `{:type "mouse" :button "left"|"middle"|"right" :down :x :y}` · `{:type "motion" :x :y}` (coalesced) · `{:type "wheel" :dy :x :y}` · `{:type "close"}` · `(gui_title w s)` `(gui_snapshot w)` → a canvas of what the window really shows · `(gui_close w)`. Under it: `(unixc path)` connects to a Unix socket, `(fdwn fd s off n)` writes part of a string/array. See `examples/connect4gui.ak` (about 125 lines).

## JS target (`node boot/ak.js`, Node interop)
`(aw promise)` (async is inferred) · `(req "mod")` `(new C args)` `(js "raw js")` `imp ev delay` · Node built-in modules and JS globals are in scope: `fs.readFileSync(f)` `Math.max(1 2)` `path.basename(p)` · `node boot/ak.js f.ak` also has `js` (print the generated JS), `build f.ak out.js` (bundle) and `exe` (embeds node). None of these exist natively.

## Terminal (native only)
`(isatty)` stdin is a terminal · `(termsize)` → `[rows cols]` (nil if stdout is not a terminal) · `(rawmode f)` runs `(f)` with the terminal in raw mode (no echo, no line buffering, Ctrl-C is just a key) and always restores it, even if `f` throws · `(getkey ms)` → the next key as `"up" "down" "left" "right" "enter" "esc" "tab" "backspace" "ctrl-c" "eof"`, or the typed character (UTF-8 aware); nil when `ms` milliseconds pass without input (no `ms`: wait). Draw by writing ANSI escape sequences with `(fdw 1 s)` (one write per frame avoids flicker) — see `examples/connect4.ak`.
